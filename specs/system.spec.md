# Системная спецификация OffScreenCanvas

Статус: Действует как описание текущего состояния
Версия: 0.1

## 1. Назначение

OffScreenCanvas демонстрирует передачу HTML canvas из main thread в Web Worker и отрисовку большого набора движущихся частиц вне основного потока браузера.

## 2. Область

- статическая страница без сборки и внешних runtime-зависимостей;
- `index.js` как main-thread bootstrap;
- `worker.js` как исполнитель 2D-анимации;
- передача `OffscreenCanvas` через `postMessage`.

## 3. Функциональные требования

### FR-001 Инициализация canvas

Страница должна находить `#mainCanvas` размером 800×600 и передавать управление им worker.

### FR-002 Worker-анимация

Worker должен получить `OffscreenCanvas`, создать 2D-контекст и непрерывно отрисовывать 10 000 движущихся частиц с отражением от границ.

### FR-003 Совместимость

До передачи управления система должна проверять поддержку `Worker`, `OffscreenCanvas` и `transferControlToOffscreen`, а при отсутствии поддержки показывать понятное состояние вместо необработанной ошибки.

### FR-004 Контракт сообщений

Сообщения canvas и `MessagePort` должны различаться явным полем типа. Worker не должен интерпретировать сообщение порта как сообщение canvas.

## 4. Нефункциональные требования

### NFR-001 Простота

Демонстрация должна оставаться запускаемой как три статических файла без package manager, bundler или framework.

### NFR-002 Диагностируемость

Ошибки создания worker, передачи canvas, получения контекста и обмена сообщениями должны быть видимы пользователю или в консоли.

## 5. Текущее соответствие

| Требование | Состояние |
|---|---|
| `FR-001` | Реализовано для поддерживаемых браузеров |
| `FR-002` | Реализовано |
| `FR-003` | Не реализовано: feature detection отсутствует |
| `FR-004` | Не реализовано: оба сообщения обрабатывает один canvas-only handler |
| `NFR-001` | Реализовано |
| `NFR-002` | Частично реализовано |

Эта SPEC фиксирует обнаруженные расхождения, но текущий rollout КАРКАСА не изменяет продуктовый код.

## 6. Критерии приёмки

- AC-001 В поддерживаемом браузере canvas передан worker и частицы анимируются.
- AC-002 В неподдерживаемом браузере отображается понятное состояние без необработанной ошибки.
- AC-003 Передача `MessagePort` не вызывает обращение к отсутствующему canvas.
- AC-004 В консоли нет ошибок после запуска и обмена сообщениями.
