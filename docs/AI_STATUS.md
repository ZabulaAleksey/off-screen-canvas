# Статус OffScreenCanvas

Обновлено: 2026-08-13
Текущий этап: КАРКАС подключён; надёжный контракт worker запланирован

## Реализовано

- статическая страница с canvas 800×600;
- передача `OffscreenCanvas` в Web Worker;
- worker-анимация 10 000 частиц;
- минимальный project overlay: SPEC, архитектура, решения, дизайн, roadmap и текущий план;
- наследование общей AI Dev Team без локальных generic capabilities.

## Известные проблемы

- feature detection `OffscreenCanvas` отсутствует, поэтому неподдерживаемый браузер получает необработанную ошибку;
- `MessagePort` отправляется вторым сообщением, но worker обрабатывает любое сообщение как canvas и может обратиться к `undefined.getContext`;
- ошибки worker и невозможность получить 2D context явно не обрабатываются;
- browser verification в рамках подключения КАРКАСА не выполнялась, потому что runtime-код не менялся.

## Технический долг и ограничения

- фиксированные 800×600 и 10 000 частиц;
- крупный закомментированный альтернативный renderer в `worker.js`;
- нет автоматизированных browser tests;
- назначение текущего `MessageChannel` не документировано.

## Следующее действие

Реализовать ограниченный этап из `docs/AI_PLAN.md`, начиная с уточнения назначения `MessageChannel`, затем выполнить browser smoke test.
