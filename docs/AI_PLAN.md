# Текущий план OffScreenCanvas

Статус: Готов к реализации
Этап: Надёжный контракт worker

## Цель

Закрыть `FR-003`, `FR-004`, `NFR-002` и критерии `AC-002`–`AC-004` из `specs/system.spec.md` минимальным изменением `index.html`, `index.js` и `worker.js`.

## Область

- feature detection и понятное DOM-сообщение;
- явные типы сообщений main thread ↔ worker;
- корректная обработка `MessagePort` либо удаление неиспользуемого канала после проверки намерения;
- обработка ошибок создания worker и получения 2D context;
- browser smoke tests.

## Вне области

- build system, framework и новые зависимости;
- redesign, controls частиц и responsive canvas;
- изменение количества частиц или алгоритма анимации;
- локальные agents, Skills, hooks, MCP, config или Git workflow.

## Проверки

- запуск через простой локальный HTTP server;
- поддерживаемый browser: анимация и отсутствие console errors;
- неподдерживаемый/замоканный сценарий: понятное DOM-сообщение;
- отдельные сообщения canvas и порта не смешиваются.

## Definition of Done

- критерии `AC-001`–`AC-004` подтверждены;
- runtime diff ограничен тремя текущими файлами;
- SPEC и фактическое поведение согласованы;
- `docs/AI_STATUS.md` обновлён после проверки.

## Условие остановки

Если назначение `MessageChannel` нельзя установить из существующего контекста, зафиксировать вопрос и не выдумывать протокол.
