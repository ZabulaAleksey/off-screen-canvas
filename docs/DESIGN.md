# Дизайн OffScreenCanvas

## Текущее состояние

Проект не имеет оформленной дизайн-системы. Единственный экран использует стандартный белый фон браузера и canvas 800×600 без внешних controls, typography, theme tokens или reusable-компонентов.

## Канонические правила текущего этапа

- Canvas является главным и единственным визуальным объектом.
- Анимация использует разноцветные частицы на прозрачном canvas поверх белого фона.
- UI-зависимости и CSS framework отсутствуют.
- Loading, error и unsupported states пока визуально не реализованы; их добавление должно быть простым, текстовым и доступным.
- До отдельного требования фиксированный размер canvas сохраняется; responsive behavior не определён.

## Доступность

Будущее сообщение о неподдерживаемом браузере должно быть доступно как обычный DOM-текст, а canvas должен получить краткое текстовое описание.
